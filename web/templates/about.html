Sistem Deteksi Hama Babi Hutan dan Tikus

Sistem ini merupakan implementasi algoritma YOLOv7 untuk mendeteksi hama babi hutan dan tikus pada perkebunan kelapa sawit. Sistem mampu melakukan pendeteksian melalui gambar, video, maupun kamera secara realtime sehingga proses identifikasi hama menjadi lebih cepat dan efisien.

Metode

YOLOv7

Framework

PyTorch

Bahasa

Python

Web

Flask

Kelas Objek

No Nama Objek Keterangan
1 Babi Hutan Hama utama perkebunan kelapa sawit.
2 Tikus Hama yang menyerang buah dan tanaman kelapa sawit.

Alur Sistem

  1. Pengguna memilih menu deteksi.
  2. Mengunggah gambar, video atau menggunakan kamera realtime.
  3. Model YOLOv7 memproses input.
  4. Sistem melakukan Object Detection.
  5. Bounding Box dan Confidence ditampilkan.
  6. Hasil deteksi disimpan pada riwayat.
